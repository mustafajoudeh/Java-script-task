About Movie Explorer

Movie Explorer is an educational web project built using HTML, CSS and JavaScript.

The application uses the TMDB API to retrieve movie information and display it in a user-friendly interface.

This project demonstrates how JavaScript can communicate with external APIs using the Fetch API and JSON data.
